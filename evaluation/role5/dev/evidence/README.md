# Evidence in the slim checkout

The [index](INDEX.md) links every attempt to its local small files and archived large files. The [manifest](manifest.json) preserves the full experiment contract for 76 attempts and 63 selected runs; it deliberately still references the large artifacts omitted from this checkout.

Local: recorded run results/configurations, official report JSON, submitted/native patches where available, official execution logs, delivered candidate lists, effective task text, timing files, feedback summaries, and small provenance/annotation files.

Archived only: complete agent trajectories, full rankings, D initial-ranking snapshots, full D event JSONL, and official test output. See [archive index](ARCHIVE_INDEX.md), [archive identity](ARCHIVE.json), and [retrieval/reproduction](../docs/FULL_EVIDENCE.md). The archive includes the local small evidence too and extracts to an independent root.

Only use the extracted archive's manifest for full real-data recomputation. Published results in this checkout were computed against the complete evidence, not against this reduced subset. Do not delete manifest entries to make an incomplete run appear complete.

Raw evidence retained here is byte-identical to the original. Absolute paths within recorded JSON/log contents describe the historical host; loading uses the manifest's portable paths. labels.json contains evaluation-only file paths, not reference repair hunks, and must never be given to an agent.

Historical [annotations](annotations/README.md) are not regenerated by the unified evaluator. Source snapshots are evidence only and must not be executed. Check this checkout with its root CHECKSUMS.sha256; archived provenance checksums refer to historical exports.

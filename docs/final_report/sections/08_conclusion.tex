\section*{8. Conclusion}

Localization hints brought reference files into view earlier. Lexical--structural guidance had
the most observed repairs and lower tokens per resolved task, but its repair advantage remained
inconclusive and total token use increased. Failure-aware updates added limited benefit;
most unresolved runs had already inspected a reference file. The next step is to use repository
structure for change-impact analysis and test selection, helping agents validate complete fixes
after finding plausible locations.

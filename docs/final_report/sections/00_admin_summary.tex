\section*{Project Summary}

We study whether localization guidance helps mini-SWE-agent find relevant code without reducing
repair success. Our extension combines a Python AST index, BM25 retrieval, import-based ranking
and failure-aware updates. Using \texttt{gpt-5.4-mini}, we compare four conditions on 40 held-out
SWE-bench Verified tasks, with 224 runs including stability checks. Lexical--structural guidance
achieved the highest observed repair count, 25/40 versus 20/40 for the baseline, but the paired
difference was inconclusive (exact McNemar $p=0.13$). It also brought a reference-patch file into view at the
first model call in 30/40 tasks, versus 6/40 for the baseline. However, 60 of 71 unresolved runs
had already opened such a file. Failure feedback was delivered in 10/40 runs and improved a
reference file's rank only once. These observations suggest that file discovery can improve
while diagnosis and complete, regression-free repair remain substantial obstacles.

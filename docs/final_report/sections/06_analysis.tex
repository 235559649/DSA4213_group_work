\paragraph{Finding the file is insufficient.}
Of 71 unresolved runs, 60 had opened a reference-patch file; F2 remained the largest class
at 7--8 runs per condition (Figure~\ref{fig:failure-feedback}a). Twelve of its 29 runs
subsequently edited another file, and 56 of all failures fell on the 14 tasks nobody solved.
On \texttt{django-13590}, every condition edited the reference-fix line but broke ordinary
list/tuple lookups while repairing named tuples. Thus localization alone did not ensure
compatible behavior; the coding table and case details are in Appendix A.6.

\paragraph{Limited new evidence from feedback (RQ3).}
Fifty-two events in 23 \condD{} runs yielded 15 messages to ten runs; only five first
feedbacks reranked files, all in SymPy (Figure~\ref{fig:failure-feedback}b).
Only \texttt{sympy-18189}'s first reference-file rank improved (2 to 1), but all conditions
solved it. Of four tasks \condD{} lost to \condC{}, three received no feedback, so those
losses cannot be attributed to the added messages. These observations establish neither
a repair benefit nor feedback-induced harm; filtering details are in Appendix A.6.

\paragraph{Costs.}

% re-run (11_bc_cost); timing definitions in docs/evaluation/timing.md.
API cost was small: \$0.86--\$1.29 per condition for 40 runs, about \$0.04--\$0.06 per resolved task
(Table~\ref{tab:main}). Tokens follow a long tail: 26 of 160 runs exceeded 150k tokens, using 47\% of
all tokens while resolving 3 tasks; the proposal's 150k-token cap would have saved about a fifth of all
tokens at the risk of those three fixes. Localization time $T_{\mathrm{loc}}$ (index and ranking, before
the agent starts) is dominated by indexing: 301\,s over 40 tasks (83\% of \condC's ranking time; about
20\,s per SymPy task, under 1\,s for Sphinx and pytest), against 47\,s for loading the index and BM25
scoring and 12.5\,s for structure plus RRF. The median $T_{\mathrm{loc}}$ is 5.6\,s (\condB) and 6.0\,s (\condC) per task, versus 16--19\,s
of agent time $T_{\mathrm{agent}}$; the index is built once and shared by \condB--\condD, and failure
processing added 95\,s over all 40 \condD{} runs. Timings come from a separate re-run (Linux x86\_64,
Python 3.10.12) whose rankings matched the main runs exactly, so they show magnitudes, not exact latencies.

\paragraph{Limitations and risks.}
Forty tasks, four Python repositories, one model and repeats on eight tasks limit
generalization and leave run-to-run variation unresolved. Seeds-head ranking and the prompt
policy were selected on development tasks. Reference-patch files are imperfect targets,
passing tests does not prove correctness, and public benchmarks risk pretraining contamination.
The link between structural hints and fewer regressions remains untested. Hints must stay
advisory: \condC{} solved \texttt{sphinx-7757} outside every initial hint. Patches still need
human review; change-impact analysis and related-test selection are next steps.

\section*{7. Reproducibility and Responsible Practice}

The code is version-controlled in the project repository with \texttt{mini-swe-agent==2.4.6} pinned and API keys supplied through environment variables, never committed. Scripts cover BM25, structural ranking, RRF, agent runs, comparison and harness evaluation. The implementation was frozen (tag \texttt{frozen-2026-10-27}) before the held-out runs; Docker images were pulled before formal attempts so downloads were not timed as agent work, each run was recorded individually so interrupted batches could resume, and technical retries were kept separate from stability repeats.
Only public benchmark repositories run, each in an isolated container; repository content and tool output are treated as untrusted, and generated patches still need human review before real-world use.

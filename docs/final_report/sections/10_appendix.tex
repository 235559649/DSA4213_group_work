The ranking is explicitly described as guidance: no file is hidden from the agent, and the agent may depart from the suggested candidates when repository evidence supports doing so.

\paragraph{Failure-feedback example.}
Condition \condD{} can update the ranking after a failed command without changing the underlying repair loop. On \texttt{sympy-18189}, a failed execution produced a \texttt{RecursionError}. Repository-backed traceback evidence was recognized as usable source evidence, so the event was routed to a ranking update rather than treated only as a diagnostic message. The runtime ranking $F$ was fused with the fixed lexical and structural rankings, moving the first reference source file from rank 2 to rank 1, and a short evidence note was supplied before the next model call. The task was nevertheless solved under all four conditions, so this example demonstrates that runtime evidence can sharpen localization but does not by itself establish that the reranking caused the successful repair.
